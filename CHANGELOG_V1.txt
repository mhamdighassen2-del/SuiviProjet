================================================================
  5. FORMAT DES CODES (MODELE EXCEL)
================================================================

  REFERENCE PROJET : YYYY-CCC-DDD
    YYYY = année (ex: 2026)
    CCC  = numéro client sur 3 chiffres (ex: 052)
    DDD  = numéro dossier sur 3 chiffres (ex: 001)
    → Exemple : 2026-052-001

  CODE REPERE : YY-CCC-DDD-SSS
    YY   = 2 derniers chiffres de l'année (ex: 26)
    CCC  = numéro client sur 3 chiffres (ex: 052)
    DDD  = numéro dossier sur 3 chiffres (ex: 001)
    SSS  = séquence sur 3 chiffres (ex: 003)
    → Exemple : 26-052-001-003

  AVANCEMENT REPERE :
    Stocké en base : décimal 0.0 à 1.0
    Affiché à l'écran : 0% ou 100% (binaire comme dans Excel)
    Temps réalisé = avancement × temps_estimé (en minutes)

  AVANCEMENT PROJET (calculé automatiquement par trigger) :
    taux_avancement = SUM(avancement × temps_estime) / SUM(temps_estime) × 100

  PREREQUIS :
    - Node.js 18+
    - PostgreSQL 14+ (local ou Docker)
    - npm

  ETAPE 1 — Base de données
    Créer la base et appliquer les migrations dans l'ordre :
      psql -U postgres -c "CREATE DATABASE suivi_projets;"
      psql -U postgres -d suivi_projets -f database/migrations/001_init.sql
      psql -U postgres -d suivi_projets -f database/migrations/002_ordre_fabrication_projet_cascade.sql
      psql -U postgres -d suivi_projets -f database/migrations/003_utilisateur_service.sql

      psql -U postgres -d suivi_projets -f database/migrations/006_cellules_reperes.sql
      (si erreur schema existant → utiliser 007 à la place de 006)
      psql -U postgres -d suivi_projets -f database/seeds/seed.sql

    cd backend
    npm install
    cp .env.example .env   (puis configurer DB_HOST, DB_PORT, etc.)
    npm run dev            (démarre sur http://localhost:3000)
